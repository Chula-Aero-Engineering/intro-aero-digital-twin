# Feature Completion Checklist

- [ ] I can state the engineering question.
- [ ] I understand the governing model.
- [ ] I know the inputs and units.
- [ ] I know the outputs and units.
- [ ] I documented the model assumptions.
- [ ] I manually calculated a reference case.
- [ ] I defined expected physical behavior.
- [ ] I defined verification cases before generating code.
- [ ] AI generated only the intended bounded feature.
- [ ] I can identify where the engineering equation appears in the code.
- [ ] The automated tests pass.
- [ ] The feature matches the manual calculation.
- [ ] The feature behaves physically as expected.
- [ ] I used the feature to make or support an engineering decision.
